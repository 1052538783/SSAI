第一部分：家纺四件套 AI 生图视角指南
在 AI 绘画（如 Midjourney 或 Stable Diffusion）中，不同的视角词汇会产出完全不同的床品展示效果。以下是为你分类整理的实用指南：
1. 最常用、最出效果的“黄金角度”（电商主图首选）
四分之一视角 + 高角度 (3/4 view + High angle / from_above)
拍出来是什么样： 也就是我们常说的“斜侧方俯拍”。镜头在床的左前或右前方，微微向下看。
为什么适合： 这是家纺最经典的角度。它能同时展现床面的花型（被套）、枕头的立体感、以及床单垂在床沿的褶皱感（展现面料柔软度）。（注：你的图2就是这个角度，后面详细分析）。
正上方俯视 / 鸟瞰 (bird's nest / top-down view / directly from above)
拍出来是什么样： 镜头完全在床的正上方，垂直向下拍，像一张平面设计图。
为什么适合： 非常适合展示大面积的复杂花型、AB版拼色设计。这种角度能让顾客一眼看清四件套的完整图案排版，没有任何透视变形。
正面视角 + 平视/微高角度 (front view + eye-level / slightly from_above)
拍出来是什么样： 镜头正对着床尾，站在床的正前方看过去。
为什么适合： 适合展现对称美、酒店风、或者非常规整的纯色/简约风床品。给人一种大气、端庄的感觉。
2. 适合展现面料细节的“辅助角度”（详情页必备）
特写 + 侧面视角 (Close-up + from side)
拍出来是什么样： 镜头贴近床沿，从侧面拍摄被角、枕头边缘或者床单下垂的部分。
为什么适合： 专门用来表现面料的厚度、光泽度（如真丝/天丝）、走线工艺、蕾丝花边。
特写 + 浅景深 (Close-up + shallow depth of field)
拍出来是什么样： 聚焦在被子上的某一个花朵或褶皱，背景（如床头柜）模糊。
为什么适合： 突出面料的肌理感（如纯棉的纹理、华夫格的凹凸感），增加高级感。
3. 家纺生图需要【避雷】的角度
从下方 / 仰拍 (from_below / low angle)： 拍床如果从下往上拍，只能拍到床底或床架，完全看不到被套的花型，非常诡异，绝对不要用。
倾斜角度 (dutch_angle)： 画面是歪的，会让人感觉眩晕、不稳定，不适合需要传递“安稳睡眠”氛围的家纺产品。
鱼眼镜头 (fisheye)： 画面边缘会严重扭曲变形，导致床品花型变形，顾客无法判断真实样子。
后背视角 (from_behind)： 只能拍到床头板的背面，毫无意义。
